# History demo: three facts to check by hand (fsft at b1125d8)

Run these read-only commands in a clone of full-stack-fastapi-template. Each one should give the number shown in the UI.

1. `backend/app/api/routes/users.py` has 43 revisions and 1,188 lines of churn (+710 -478), counting non-merge commits across renames.
   `git log --follow --no-merges --format=%h b1125d8 -- backend/app/api/routes/users.py | wc -l` prints 43, and `git log --follow --no-merges --numstat --format= b1125d8 -- backend/app/api/routes/users.py | awk '{a+=$1; d+=$2} END {print a, d, a+d}'` prints `710 478 1188`.
2. `AddUser.tsx` and `EditUser.tsx` (in `frontend/src/components/Admin/`) changed together in 12 of 14 commits. The default filter counts only non-merge, non-bot commits that touch at most 30 files, not counting generated files (lockfiles, `*.gen.*`, `dist/` and similar). Co-change is a history pattern, not evidence that one change caused the other.
   `small() { git log --follow --no-merges --format='%h %aN %aE' b1125d8 -- "$1" | grep -Eiv '\[bot\]|dependabot|renovate|github-actions|pre-commit-ci' | cut -d' ' -f1 | while read -r c; do n=$(git diff-tree --no-commit-id -r -M50% --name-only "$c" | grep -Ecv '\.gen\.|\.min\.(js|css)$|(^|/)(__generated__|generated|vendor|dist|build)/|(^|/)(package-lock\.json|npm-shrinkwrap\.json|yarn\.lock|pnpm-lock\.yaml|bun\.lockb?|uv\.lock|poetry\.lock|Pipfile\.lock|Cargo\.lock|go\.sum|composer\.lock|Gemfile\.lock)$'); [ "$n" -le 30 ] && echo "$c"; done | sort; }; A=frontend/src/components/Admin/AddUser.tsx; E=frontend/src/components/Admin/EditUser.tsx; echo "$(small $A | wc -l) $(small $E | wc -l) $(comm -12 <(small $A) <(small $E) | wc -l)"` prints `12 14 12`. The `grep -Eiv` step drops commits whose mailmapped author name or email matches the default bot patterns; no bot commit touches either file, so the numbers are the same with or without it.
3. At 2d0f7742 (#622), `src/backend/app/crud/__init__.py` was deleted and `src/backend/app/crud.py` was added. Git records a delete and an add, not a rename, but about two thirds of the old file's distinct lines reappear in the new one. This is a suggested alias for a reviewer to confirm, not an established identity.
   `git show --name-status --format=%h -M50% 2d0f7742 -- src/backend/app/crud src/backend/app/crud.py` lists `A src/backend/app/crud.py` and `D src/backend/app/crud/__init__.py` (next to the other deleted `crud/` files), and `git diff 2d0f7742^:src/backend/app/crud/__init__.py 2d0f7742:src/backend/app/crud.py` shows the shared lines.

Known caveat: when a path is deleted and later re-added, its history restarts at the re-add. Records for such paths say so and carry `lineage_breaks`. See [CAVEATS.md](CAVEATS.md). On fsft this affects 4 records (churn for `CONTRIBUTING.md`, `frontend/src/index.css` and `frontend/src/utils.ts`, and the hotspot for `frontend/src/utils.ts`); none of the three facts above is affected.
